Rekam langsung atau unggah rekaman → transkrip per pembicara → notulen Indonesia formal (Gemini).

1API Key Gemini

Key hanya tersimpan di browser perangkat ini dan dikirim langsung ke server Google.
Cara membuat API key (2 menit)
  1. Buka aistudio.google.com/apikey, masuk dengan akun Google.
  2. Klik Create API key → pilih project default.
  3. Salin key (format baru diawali AQ., lama AIza — keduanya bisa) → tempel di atas → Simpan.
  4. Jangan bagikan key ke siapa pun.

⚡Mode LIVE — transkrip mengalir saat rapat

Teks muncul saat orang bicara (sambung-ulang otomatis tiap 9 menit, aman untuk rapat berjam-jam). Mode live tidak membedakan pembicara — audio ikut direkam, jadi setelah berhenti Anda bisa pilih: notulen instan dari transkrip live, atau tombol Proses di bawah untuk transkrip ulang per-pembicara. Biarkan layar menyala selama rapat.
