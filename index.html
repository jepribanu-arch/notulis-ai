1API Key Gemini

Key hanya tersimpan di browser perangkat ini dan dikirim langsung ke server Google.
Cara membuat API key (2 menit)
  1. Buka aistudio.google.com/apikey, masuk dengan akun Google.
  2. Klik Create API key → pilih project default.
  3. Salin key (format baru diawali AQ., lama AIza — keduanya bisa) → tempel di atas → Simpan.
  4. Jangan bagikan key ke siapa pun.
